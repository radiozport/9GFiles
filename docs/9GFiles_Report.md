## 📁 Feature Area 1: File Management

Everything you'd expect from a file manager — and a lot you probably haven't seen before.

### Core Operations

| Action | What it does |
|---|---|
| Copy / Move / Delete / Rename | Full control over any file or folder, including SD cards and USB drives |
| Multi-select | Tap to select many files, then act on all of them at once |
| Batch rename | Rename dozens of files in one go using a prefix, counter, or pattern |
| Drag and drop | Move files visually between two side-by-side panels |
| Long-press preview | Peek at a photo, text excerpt, or media info without fully opening a file |

### What Makes It Special

**Recycle Bin** — Deleted files are held for up to 30 days. Accidentally deleted something? Get it back instantly. No more permanent mistakes.

**File Shredder** — When you *do* want something gone for good, the 3-pass overwrite makes files forensically unrecoverable. Not just deleted — erased.

**File Split & Combine** — Break large files into smaller parts for easy transfer to another device, then reassemble them when you're ready.

**Timestamp Editor** — Change when a file was last modified. Useful for reorganising a library of photos or documents to reflect when something actually happened.

**Pin to Home Screen** — Any folder can be pinned as a shortcut on your Android home screen. Your Downloads or Work folder, one tap away.

## 🧭 Feature Area 2: Navigation & Interface

Finding your way around your files should feel natural, not like solving a puzzle.

### How Navigation Works

**Dual-Pane Split View** — Open two folders side by side on the same screen. Drag a file from the left panel into the right. No more copying the path, navigating away, pasting, navigating back. It works the way a desktop file manager has always worked — finally on Android.

**Tappable Breadcrumb Path Bar** — The bar at the top always shows your full current path: `Storage / Downloads / Podcasts`. Tap any segment to jump straight there. No back-button mashing required.

**Navigation History** — Separate back and forward buttons for folder navigation. Just like a browser or desktop file manager, entirely independent of Android's system back gesture.

**Per-Folder Sort Memory** — Your Music folder stays sorted by name. Your Downloads folder stays sorted by date. Each folder independently remembers its last sort setting.

**Recent Folders** — The home screen shows your most recently visited folders. Your most-used locations are always one tap away.

**Bookmarks** — Save any path permanently. Accessible from the side navigation drawer at any time.

**File Tags** — Attach coloured labels to files for your own grouping system. Works across any folder, any location.

**View Density** — Three display densities: compact, normal, or comfortable. Choose how much information you see per row.

## 🔍 Feature Area 3: Search & Discovery

### Search Methods Available

**Standard filename search** — Type part of a name and find it instantly across your entire storage.

**Full-text / content search** — This is where 9G Files stands apart. It searches *inside* files — not just their names. Open a document from three years ago by searching for a sentence you remember. Supported file types include `.txt`, `.json`, `.xml`, `.kt`, `.java`, `.py`, and more.

**Regex search** — For power users: use regular expressions to match complex filename patterns. Search for anything that looks like a date, a serial number, or a code prefix.

**Type filter** — Show only images, videos, audio, documents, archives, APKs, or code files. Cut through the noise instantly.

**Size filter** — A slider to find files smaller or larger than a given size. Great for clearing space.

**Date filter** — Narrow results to files created or modified within a specific date range.

**Search history** — Recent searches appear as suggestions. No retyping.

**Category tiles** — On the home screen, tap Images, Videos, Audio, or Documents to instantly browse every file of that type on your device — no search needed.

## 🔐 Feature Area 5: Security & Privacy

### Protection Layers

**File Encryption (AES-256-GCM)** — The same encryption standard used by banks and governments. Set a password, and the file becomes completely unreadable to anyone who doesn't have it. The encrypted file can sit on your phone, on a cloud drive, or sent anywhere — it's protected wherever it goes.

**Secure Vault** — A hidden folder locked behind your fingerprint or face. Files moved into the vault are invisible to every other app on the device. They don't appear in the gallery, in other file managers, or in any system media scan.

**App Lock** — Require a fingerprint or PIN before 9G Files even opens. Even if someone picks up your unlocked phone, they can't get into your files.

**Password-Protected ZIP** — Compress and lock files into an AES-256 encrypted archive. Send it to anyone — they need the password to open it.

**Checksum Verifier** — Confirm that a downloaded file hasn't been corrupted or tampered with. Supports MD5, SHA-1, and SHA-256. Essential for verifying software downloads.

**File Shredder (3-pass)** — Overwrites file data three times before deleting. Forensic recovery tools cannot retrieve the original content.

**File Permissions Viewer** — See exactly what read, write, and execute permissions are set on any file, displayed in the standard Unix `rwxr-xr-x` format.

### Privacy Commitment

9G Files operates entirely on your device. It does **not**:
- Send your files or file names to any server
- Connect to any external server (except ones you configure yourself, like your own FTP or NAS)
- Collect analytics or usage data
- Display advertisements

## 🌐 Feature Area 6: Network & Remote Access

### Connection Types Supported

**SMB / Samba (NAS & Windows shares)** — Connect to your home NAS or a Windows shared folder. Browse it exactly like a local folder on your phone. Great for watching videos stored on a NAS, or accessing work files on a shared drive.

**FTP & SFTP Client** — Connect to any remote FTP or SFTP server and transfer files in both directions.

**WebDAV Client** — Works with servers like Nextcloud and ownCloud.

**Cloud Storage** — Browse and manage Google Drive, OneDrive, Dropbox, and Box directly — no separate app required, no additional logins. Uses Android's built-in Storage Access Framework.

**FTP Server (Phone → PC)** — Turn your phone into a file server. Connect from any PC on the same Wi-Fi network using Windows Explorer or any FTP client. A QR code is generated automatically for the address, so connecting takes seconds.

**Wi-Fi Direct** — Transfer files directly between two Android phones. No router, no internet, no cables. Just two phones and a direct wireless link. Either device can initiate a send at any time.

**Chromecast / Cast to TV** — Stream any video or audio file from your phone to a Chromecast or compatible smart TV over your home Wi-Fi.

## ⚙️ Feature Area 7: Storage Analysis & System Tools

### Understanding Your Storage

**Storage Treemap** — A visual, colour-coded map of what's using your space. Each file type gets its own colour; tap any section to drill deeper. See at a glance whether it's videos, photos, or app data taking up the most room.

**Duplicate Finder** — Scans your storage and groups files that are identical (by content, not just name). Review the duplicates and delete the copies you don't need.

**Large Files Finder** — Lists everything on your device sorted by size. Find and remove the biggest space-wasters in seconds.

**Empty Folder Cleaner** — Finds and removes leftover empty folders that other apps create and never clean up.

**App Manager** — See every installed app. Back up its APK file, jump to its settings page, or uninstall it — all from one place.

**Storage Breakdown** — A category-by-category view of your internal and external storage usage.

**Print** — Send any image or PDF directly to a wireless printer without opening any other app.

**QR Code Sharing** — Generate a QR code for your FTP server address or any file path to share it instantly.
